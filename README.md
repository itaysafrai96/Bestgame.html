# גיבורי הכתר האבוד — Heroes of the Lost Crown

משחק אסטרטגיה בדפדפן מבית **Emberforge Animation Studios** (בדיוני):
- **מפת הרפתקאות** בסגנון Heroes 3/5 — עולם אקראי, ערפל מלחמה, מכרות, אוצרות, מקדשים, מפלצות שומרות, ימים ושבועות.
- **עיר** בסגנון Heroes 5 — 15 מבנים, גיוס 7 דרגות יצורים, גילדת קוסמים, שוק וחיל מצב.
- **קרבות בזמן אמת עם הפסקה** בסגנון Baldur's Gate 2 — בחירה בגרירה, פקודות, הטלות d20, לחשים (כדור אש עם פגיעה ידידותית!), יכולות מיוחדות, לוג קרב.
- **שדרוגי יצורים** (כמו ב-Heroes 3/5) — 7 יצורים משודרגים (הלברדאי, צלף, גריפון מלכותי, צלבן, קנאי, אלוף, ארכי-מלאך), מבני שדרוג ושדרוג ערימות קיימות בעיר.
- **גיבור אויב** — נקרומנסר שמוביל את צבא המתים, מטיל חיצי מוות וקללות ומקים חיילים מן המתים. מתחזק בכל מערכה.
- **מצור על העיר** — חומות, מגדלי חצים עם קשתים יורים, וחיל המצב נלחם לצד הגיבור.
- **אנימציה, אפקטים ומוזיקה** — כל הדמויות, החלקיקים, הסאונד והמוזיקה (4 נושאים) נוצרים בקוד בזמן אמת. אין קבצי מדיה.

## הפעלה
פשוט לפתוח את `index.html` בדפדפן (Chrome/Edge/Firefox). לחיצה ראשונה מפעילה את הסאונד.

## מקשים
- מפה: לחיצה = נתיב, לחיצה שנייה = תנועה · `E` סיום תור · `T` עיר · `H` גיבור · חיצים/WASD גלילה
- קרב: `רווח` הפסקה · `A` בחר הכל · `1-8` יחידה · `Q` יכולת · `Esc` ביטול · לחיצה ימנית = פקודה

# 🎲 אמת או חובה — `truth-or-dare/`

משחק מסיבות בעברית, קובץ אחד שעובד גם בטלפון: לפתוח את `truth-or-dare/index.html`.
- **5 רמות** (אפשר לשלב): 🎉 חברים · 🔥 נועזים · 💕 זוגות · 🌶️ פיקנטי (18+) · 🧠 עומק — כ-310 שאלות ומשימות.
- **ניקוד** (אמת = 1, חובה = 2, הגרלה = בונוס), **2 ג'וקרים** לכל שחקן, **עונשים** למי שמוותר.
- **משימות עם שחקנים** — `{p}` מוחלף בשחקן אקראי; **טיימר** אוטומטי למשימות עם זמן.
- **אירועים מיוחדים** ⚡ (סבב מהיר, החלפת מקומות, שתיקה…), בלי חזרות עד שהחפיסה נגמרת.
- **הוספת שאלות ומשימות משלכם**, שמירה אוטומטית של השחקנים וההגדרות.

# 🎡 אמת או חובה · THE GANG — `bump/`

גלגל מסתובב לחברים 18+: לפתוח את `bump/index.html`.
- **4 קטגוריות על הגלגל**: אמת · חובה · סוד (בוחרים 1 מ-3 נושאים) · באמפ (כ-400 שאלות, משימות וסודות 18+, בסדר אקראי ובלי חזרות).
- **מונה באמפים** — כל באמפ שיוצא בגלגל נספר, ו**באמפ 10, 20, 30… = באמפ לכולם!** 🍻.
- **תמונה במרכז הגלגל** — לוחצים עליה כדי לסובב; אפשר להחליף אותה בהגדרות.
- שחקנים (לא חובה), טיימר למשימות, צלילים, רטט וקונפטי. הכל נשמר בטלפון.

# 🎡 3 גרסאות נוספות — `versions/`

אותם חוקי בסיס כמו `bump/` (גלגל, תמונה במרכז, באמפ לכולם כל 10, משחק חדש, מצב הרצה), עם מנוע משותף (`versions/engine.js`) ותבנית (`versions/template.html`).
- **🔥 אש** (`versions/heat/`): אמת · חובה · סוד · באמפ, ושלוש רמות חום שעולות לבד לאורך הערב (או ידנית).
- **🪩 מי פה?** (`versions/club/`): אף פעם לא · מי הכי · סוד · באמפ. כולם משחקים בכל סיבוב.
- **❤️‍🔥 בשניים** (`versions/duo/`): נשיקה · אמת זוגית · חובה זוגית · באמפ. כל סיבוב מגריל פרטנר.

אחרי שינוי ב-`engine.js` או ב-`template.html` מריצים `python3 versions/build.py`.
